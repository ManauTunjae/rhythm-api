# 🎵 Rhythm API

Rhythm API är en backend-tjänst byggd med **MERN-stacken** (MongoDB, Express, React, Node.js - i detta 
skede fokus på de tre sistnämnda). Projektet är inspirerat av musiktjänster och tillåter användare att hantera artister och låtar genom ett RESTful API.

## 🚀 Funktioner
- **CRUD för Artister:** Skapa, hämta, uppdatera och radera artister.
- **CRUD för Låtar:** Hantera biblioteket av låtar.
- **Validering:** Säkerställer att rätt datatyper skickas till databasen.
- **MongoDB Integration:** Persistent lagring med Mongoose-scheman.

## 🛠 Teknikstack
- **Node.js** & **Express** (Server)
- **MongoDB** & **Mongoose** (Databas & Modellering)
- **Dotenv** (Miljövariabler)
